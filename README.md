# Twitch Random Badge — Браузерное расширение

Расширение автоматически меняет значок в чате Twitch при каждом отправленном сообщении.

## Установка

### Chrome / Edge / Brave:

1. Откройте `chrome://extensions/` или `edge://extensions/`
2. Включите **Режим разработчика** (переключатель в правом верхнем углу)
3. Нажмите **Загрузить распакованное расширение**
4. Выберите папку `Twitch_Badges_Extension`
5. Иконка расширения появится на панели инструментов

## Использование

1. Откройте любой стрим на Twitch с чатом
2. Расширение активируется автоматически
3. Каждое отправленное сообщение будет иметь новый значок из вашей коллекции
4. Нажмите на иконку расширения для настройки

## Настройки

- **Расширение включено** — включение/выключение ротации
- **Последовательный режим** — перебор бейджей по порядку вместо случайного выбора. Позиция запоминается и сохраняется между сессиями

## Как это работает

При отправке сообщения расширение:
1. Перехватывает нажатие Enter или клик по кнопке отправки
2. Открывает пикер бейджей (невидимо для пользователя)
3. Сканирует доступные персональные бейджи
4. Фильтрует и исключает неподходящие значки
5. Выбирает бейдж (случайно или по порядку)
6. Отправляет сообщение с выбранным значком

Работает на основной странице Twitch и в popout-чате.

Поддерживается быстрая отправка — сообщения встают в очередь и обрабатываются последовательно.

## Исключённые бейджи

Расширение автоматически исключает из ротации:

- **Роль-бейджи**: Владелец канала, Модератор, VIP, Партнёр/Сотрудник/Стажёр Twitch
- **Служебные бейджи**: Только прослушивание (`no_video`), Просмотр без звука (`no_audio`), Отсутствует

Если для канала установлен специальный значок, ротация пропускается.

## Требования

- Chrome 88+ / Edge 88+ / Brave или любой Chromium-браузер
- Авторизация на Twitch
- Открытый чат

## Конфиденциальность

Расширение не собирает и не передаёт никакие данные. Все настройки хранятся локально в браузере. Расширение взаимодействует только с интерфейсом чата Twitch на вашем компьютере.
